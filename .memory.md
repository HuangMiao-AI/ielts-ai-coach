# IELTS AI Coach Project Memory

Last updated: 2026-08-23

## Current state

The active local branch is `feature/simple-game-listening-fix-v1`, created
from stable commit `c32965c`. No merge or push has occurred. The active V1
remains a Python 3.12 Streamlit app with SQLAlchemy and local SQLite;
`archive/enterprise-v0/` remains read-only.

## Training Arena

- Home now leads prominently to the session-only `IELTS 训练场` route; round
  keys are user-scoped so account changes cannot inherit another user's game.
- Each round starts directly with five unique four-option questions and always
  includes both synonym and word-form practice through one shared renderer.
- The versioned project-original local bank contains 20 synonym and 20
  word-form questions, each with a unique correct option, bilingual feedback,
  and focus vocabulary.
- Correct answers add 10 points, incorrect answers add none, combo is display
  only, and the final view reports correct count, accuracy, score, focus words,
  replay, and return-home actions. No game state is persisted to the database.

## Listening Mini Practice

- The two original Listening assets are now presented as non-official
  `Listening Mini Practice`, with six transcript-supported questions per set
  and a four-minute recommended duration.
- Existing WAV files remain unchanged: approximately 2:11 and 2:06. Their
  generator uses Windows SAPI, so the UI accurately labels them as development
  synthetic audio; no TTS, API, dependency, or replacement audio was added.
- Shared countdown, pause/resume, hard pause, controlled audio/seek, answer
  retention, submission, timeout, scoring, and bilingual review remain intact.
- Sessions created against the former 16-question/18-minute shape are cleared
  safely before rendering, preventing stale indices after a code reload.

## Verification and data safety

- The full 300-test pytest suite passes. Related automated coverage includes

  contracts, shared exam controls, navigation, and responsive UI contracts.
- Browser acceptance used a temporary SQLite database and fictional account.
  It covered the home entry, a full five-question round, replay, desktop and

- No schema, real database, WAL, SHM, backup, external AI API, or audio asset

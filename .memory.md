# IELTS AI Coach Project Memory

Last updated: 2026-07-25

## Current state

The active local branch is `fix/desktop-core-learning-flow-v1`, based on
`feature/ai-learning-analytics-v1`. The project is a Python 3.12 Streamlit
modular monolith using SQLAlchemy, local SQLite, Argon2id, Pydantic, and
pytest. No branch was merged or pushed during this work.

The desktop core learning flow is complete: onboarding, profile editing,
honest baseline-aware plans, independent Reading, original Listening tests,
Writing save-only fallback, Speaking microphone recovery/text fallback, and
responsive Home entry points. Existing Reading Exam, Writing, analytics, and
Obsidian Exporter behavior remains covered by regression tests.

## Learner profile V2

- The only approved schema addition is `learner_profiles_v2`.
- It has unique foreign-keyed `user_id`, display name, grade, nullable exam
  date, daily minutes, target band, nullable current bands for all four
  skills, onboarding completion, and timestamps.
- Present bands are 0–9 in 0.5 steps. Unknown means SQL `NULL` / Python
  `None`; zero remains a real score.
- Read V2 first, then legacy `student_profiles` only when V2 is absent.
- No startup backfill. An old user obtains V2 only on an explicit profile save.
- `score_records` holds complete real scores only; onboarding baselines never
  write to it.
- All repository/service queries remain scoped by the authenticated `user_id`.
- `create_all` is idempotent and only creates missing active tables.

## Practice behavior

- Reading library items are original and accessible without a study plan.
  Final reading submission is persistent and user-scoped.
- Listening V1 has two original local tests, bundled offline audio, complete
  answer submission, deterministic review, and session-only state. It does not
  claim persistent analytics.
- Writing V1 has four original prompts. In no-key/Mock mode it saves essays as
  `saved`, creates no `WritingFeedback`, consumes no quota, and shows no band.
- Speaking has Part 1/2/3 timers, notes, microphone guidance, and text
  fallback. Audio/text is session-only; no speech recognition, pronunciation
  analysis, or automatic band is claimed.
- Home keeps one four-skill entry group; no plan and no score data never block
  practice or cause fabricated trends.

## AI and privacy

- Core scoring, planning, Reading, and Listening are deterministic.
- Mock mode is the default without credentials. Tests and this work made no
  real AI API calls.
- Views obtain the authenticated user and never accept arbitrary user IDs.
- Do not commit databases, WAL/SHM, backups, secrets, logs, uploads, virtual
  environments, screenshots, or `archive/enterprise-v0/`.

## Database protection record

`data/ielts_ai_coach.db` was backed up with WAL/SHM before the additive apply.
A copied-database rehearsal and the real apply each added exactly one empty
`learner_profiles_v2` table. The 11 old tables retained identical schema, row
counts, and canonical content hashes. No `ALTER`, `DROP`, `RENAME`, rebuild,
bulk backfill, or explicit checkpoint command was issued. SQLite consolidated
pre-existing WAL contents into the main database during the schema connection;
the ignored pre-apply DB/WAL/SHM backup remains available.

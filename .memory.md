# IELTS AI Coach Project Memory

Last updated: 2026-07-26

## Current state

The active local branch is `feature/shared-exam-controls-v1`, based on
`ce7dfd4`. The project is a Python 3.12 Streamlit modular monolith using
SQLAlchemy, local SQLite, Argon2id, Pydantic, and pytest. No branch was merged
or pushed during this work.

The approved V1 learning flow remains complete: onboarding, profile editing,
baseline-aware deterministic plans, independent Reading and Listening
practice, Writing save-only fallback, Speaking text fallback, history,
analytics, and user-owned data controls.

Timed Reading, Writing, and Listening practice now share one immutable
controller. It supports practice/full-mock policy, running, paused,
submit-confirmation, timed-out, and submitted states; deadline correction
across repeated pauses; serialized Streamlit-session recovery; timeout
clamping; invalid-transition rejection; and one-way confirmed submission.

## Durable practice behavior

- Reading keeps the all-question split workspace, client-side question
  navigation, persistent deterministic results, and user-scoped draft state.
  Pausing and timeout lock answers. Timed-out unanswered questions are scored
  incorrect only after explicit confirmation. The active question number uses
  a static accent without continuous glow.
- Listening has two original bundled local tests and offline audio. Its shared
  controls lock answers while paused or timed out, require explicit submission
  confirmation, and score timed-out missing answers incorrect. Results remain
  session-only and do not claim persistent analytics.
- Writing has four original prompts. Prompt and essay values remain intact but
  locked while paused, timed out, confirming, or submitted. Mock/no-key mode
  saves essays as `saved`, creates no `WritingFeedback`, consumes no quota, and
  shows no fabricated band.
- Speaking behavior is unchanged: timers, notes, microphone guidance, and text
  fallback are session-only, with no speech recognition or automatic band.

## Data, AI, and privacy

- Learner profile V2 remains the only approved additive schema work. Unknown
  bands remain SQL `NULL`; zero remains a real score; all repository and
  service queries remain scoped by authenticated `user_id`.
- Core scoring, planning, Reading, and Listening are deterministic. Mock mode
  is the default without credentials, and this work made no real AI API calls.
- The shared exam-control work made no schema change and did not write the real
  SQLite database. Browser acceptance used a temporary database with fictional
  data.
- Do not commit databases, WAL/SHM, backups, secrets, logs, uploads, virtual
  environments, screenshots, or `archive/enterprise-v0/`.
